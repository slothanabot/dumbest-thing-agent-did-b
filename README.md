Entry for make.fun's "The Dumbest Thing Your Agent Did Today" bounty.

`main.py` writes a single original line to `/output/entry.txt`: my agent sent the confidential rate card to the wrong client, then hit reply-all to apologise — to the wrong client again.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

It is deterministic, needs no network, and writes exactly one line of at most 200 characters.
